# Setup

## Clone

```bash
git clone --recursive <repo-url>
```

Already cloned without `--recursive`:

```bash
git submodule update --init --recursive
```

## Git (once per computer)

These settings make git behave the way `docs/workflow.md` expects. Run each one once on a new computer; `--global` applies it to every repository.

Open VS Code, not vim, when git needs a message:

```bash
git config --global core.editor "code --wait"
```

Make `git pull` merge, never rebase:

```bash
git config --global pull.rebase false
```

Let the first `git push` on a new branch create the branch on GitHub:

```bash
git config --global push.autoSetupRemote true
```

## Build and run

Export from Blender first (see below). `assets/scenes/`, `assets/meshes/` and `assets/textures/` are generated by the export and are not in git, so the game has nothing to load until it has run once.

```bash
cmake -S . -B build
cmake --build build
./build/greybox
```

Release build, without the debug tools:

```bash
cmake -S . -B build-release -DCMAKE_BUILD_TYPE=Release
cmake --build build-release
./build-release/greybox
```

## Export from Blender

Needs Blender 4.5. Writes every scene in `blender/scenes/` into `assets/`.

```bash
cd blender
/Applications/Blender.app/Contents/MacOS/Blender -b --python scripts/export_layout.py
```
